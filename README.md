# 🌿 Gedeo Cultural Heritage Website

> **Discover • Preserve • Celebrate • Share**

A modern digital platform dedicated to documenting and showcasing the **Gedeo cultural heritage of Ethiopia** through history, traditions, visual storytelling, and cultural experiences.

## 🌍 About the Project

The **Gedeo Cultural Heritage Website** is designed to digitally preserve and present the unique cultural identity of the Gedeo people.

The platform brings together cultural stories, **Daraaro**, Gedeo history, the Gada system, Songo, traditional knowledge, photographs, videos, and an Ethiopian calendar experience in one interactive website.

### 🎯 Project Goals

* 🏛️ Preserve Gedeo cultural heritage digitally
* 🌿 Share Gedeo traditions and history
* 🎉 Showcase **Daraaro — Gedeo New Year**
* 📸 Present Gedeo culture through photography and visual storytelling
* 🎥 Document cultural videos and experiences
* 📚 Make cultural knowledge accessible to younger generations
* 🌍 Introduce Gedeo heritage to a wider global audience

---

## ✨ Features

### 📅 Ethiopian Calendar

An interactive Ethiopian calendar experience with cultural dates and important occasions.

### 🎉 Daraaro

A dedicated cultural experience for **Daraaro**, featuring:

* Countdown
* Cultural timeline
* Daraaro calendar card
* 3D visual gallery
* Cultural videos
* Festival information
* Gedeo New Year storytelling

### 📖 Cultural Context

Explore the cultural background, traditions, values, and identity of the Gedeo people.

### 🏛️ History

A dedicated section for learning about Gedeo history and heritage.

### 📝 Cultural Memo

A space for cultural notes, stories, memories, and important information.

### 📸 Songo

A visual storytelling section showcasing Gedeo landscapes, traditions, architecture, and cultural scenes.

### 🌀 Gada System

Information about the traditional Gada system and its cultural significance.

### 📊 Dashboard

A centralized cultural and calendar dashboard for exploring important information.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/gedeo-cultural-heritage.git
```

### 2. Open the project

```bash
cd gedeo-cultural-heritage
```

### 3. Run locally

You can simply open:

```text
index.html
```

Or use a local development server:

```bash
py -m http.server 5500
```

Then open:

```text
http://localhost:5500
```
